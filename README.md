📊 Amazon Sales Analytics Dashboard – Power BI Project
📁 Project Overview ::
This Power BI dashboard provides a comprehensive analysis of Amazon sales data, focusing on sales performance, profit distribution, and order trends across categories and states. It is designed to offer actionable insights for business decision-makers to improve profitability and customer targeting.

🧩 Features Included ::
Total Sales: ₹725.46K
Total Orders: 3,203
Total Profit: ₹108.42K
Time Series Analysis: Line graph showing daily sales trends from 2011 to 2014.
Category Performance: Treemap showing the total sales by product categories.
State-wise Profit Distribution: Bar chart visualizing profit by U.S. states.
Sales Gauge: Interactive gauge chart representing total sales against a benchmark (₹1M).

📌 Key Insights ::
Top Sales Categories:
Chairs: ₹101.78K
Phones: ₹98.68K
Tables: ₹84.75K
Highest Profitable State: California (₹76K profit)
States with Losses: Colorado (-₹7K), Arizona (-₹3K), Oregon (-₹1K)
Peak Sales: Observed at certain intervals with spikes across years, indicating seasonal or promotional impacts.
